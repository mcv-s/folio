FAQ

Is Folio Free?

Yes, Folio is completely free to use. All the features you see here will be free, forever.

Why isn't Folio available on Web Stores?

I don't have the resources to go through the review process for each store, so it's only an unpacked extension for now.

Why did you make Folio?

I got bored of clutter :)

What makes Folio different?

It's designed with simplicity and customization in mind. Everything is fully customizable - you can even use custom CSS!
Setup
  1. Download the latest version of the extension from GitHub.
  2. Unzip the extension.
  3. Go to your browser's extensions page.
  4. Enable Developer Mode if it is not already enabled.

  5. Select Load Unpacked.

  6. Select the unzipped Folio extension folder and you're ready to go!
Yes - it's a bit sketchy to load unpacked extensions, but this is the only way to use Folio until it's published on the Edge/Chrome Addons Store.
